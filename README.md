# Not Fight Club
[Live demo](https://vetavv.github.io/not-fight-club/)  

This is a study project built for frontend practice.  
A browser-based turn-based mini-game inspired by classic fighting games and reimagines the format as 
a light underwater duel.

## Tech Stack

- JavaScript
- HTML
- CSS

## How To Play

1. Open the main game page.
2. Click `New fight`.
3. Enter the player name.
4. Choose a hero and an enemy.
5. In each round, select the required number of defense and attack zones.
6. Click `Strike`.
7. The game ends when one fighter's health reaches zero.

The number of selectable zones depends on the chosen character's stats.
